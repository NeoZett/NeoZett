### 2. Background 📜

I am sixteen years old and started programming at around ten. Initially, it was
mostly web-development through a webbsite called [koda.nu](https://koda.nu) and
it wasn't until much later that I started with HTML development.

After doing this for a some time, I had found myself a rabbit hole; and I
explored many different software utilities, such as [node.js](https://nodejs.org/en)
and batch files before I started with [Python](https://www.python.org/) development.

It was using Python that I first learned networking, parsing, and libraries, such
as the [PyGame](https://www.pygame.org/news) library and later SDL.

Finally, after already having learned a lot about the C-languages, I started
programming in C++. And that is where I am today.

My favorite languages are all of the C-languages and Assembly because I am
fascinated with Computer Science and how programming languages work.
